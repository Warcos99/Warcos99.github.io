# ArduDeck

ArduDeck is an *Arduino cyber-deck* or something like it.  It is a printable PCB and code base that allows for a quick integration of an Arduino, screen, buttons, and menu code-base.  This in theory should allow anyone using this infrastructure to make whatever apps they wish for their Arduino based cyber-deck.

The GitHub Page goes into a little more detail into how it all works, so here I'm just going to show off what it is and what it can do!
